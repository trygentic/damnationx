# Sample provenance

All images in this directory were generated as original, abstract pixel-art fixtures for the sample asset package. They are not extracted, traced, or copied from Diablo, Hellfire, DevilutionX, DamnationX, or any proprietary archive. They were made from fixed palette tuples by a deterministic PNG generator; no game data is required to redistribute this directory.

License: CC-BY-4.0. Attribution: DevilutionX contributors, “DamnationX Original Pixel Samples”.

The files intentionally use 16x16 RGBA PNGs so validation and renderer fixtures remain small. Normal maps use tangent-space RGB conventions; absent emissive/normal channels must exercise the manifest fallbacks.
