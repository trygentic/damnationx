# DXM-A06 sample provenance

All images in this directory were generated as original, abstract pixel-art fixtures for DXM-A06. They are not extracted, traced, or copied from Diablo, Hellfire, DevilutionX, DamnationX, or any proprietary archive. The source palette tuples and deterministic PNG generator are recorded in the producing change; no game data is required to redistribute this directory.

License: CC-BY-4.0. Attribution: DevilutionX contributors, “DXM Original Pixel Samples”.

The files intentionally use 16x16 RGBA PNGs so validation and renderer fixtures remain small. Normal maps use tangent-space RGB conventions; absent emissive/normal channels must exercise the manifest fallbacks.
